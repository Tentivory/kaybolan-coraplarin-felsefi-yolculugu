# Kaybolan Çorapların Felsefi Yolculuğu

Bu repository, modern insanlığın en büyük gizemlerinden birini, yani **kaybolan çorapların** varoluşsal krizini ele alan, bilim ve felsefeyi absürt bir şekilde harmanlayan epik bir projedir.

## Nedir Bu?

Her gün çamaşır makinesinden çıkan çorapların yarısı nereye gidiyor? Paralel evrenlere mi? Kara deliklere mi? Yoksa sadece sizinle dalga geçmek için mi saklanıyorlar?

Bu kod, o sorulara cevap arar. Ama bulamaz. Çünkü cevap yoktur. Veya belki vardır ama kod çok tembeldir.

## Nasıl Çalıştırılır?

```bash
python corap_felsefesi.py
```

Çıktı olarak size sonsuz döngüde çorapların kayboluş hikayelerini anlatır. Ctrl+C ile kurtulabilirsiniz. Belki.

## Özellikler

- Rastgele çorap renkleri üretir (kırmızı, mavi, yeşil, siyah, ve 'kaybolmuş')
- Her çorap için derin felsefi sorular sorar
- Asla çözüm önermez, çünkü hayat böyledir
- Çoraplarınızı geri getirmez (garanti)

## Uyarı

Bu kodu çalıştırırsanız, çoraplarınız daha da hızlı kaybolabilir. Sorumluluk kabul etmiyoruz.
